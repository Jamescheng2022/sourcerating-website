# Historical technical review artifacts

`photo-manifest.json` in this directory is a **historical intermediate manifest**
from preparation of the nine-article expansion. Its working paths, filenames,
dimensions and hashes do not represent the final website's 64-image inventory.
It is retained as preparation history, not as a release-validation input.

Use `docs/editorial-photo-provenance-20261104.json` for the current 64-file
provenance inventory and `src/data/editorial-media.json` plus the canonical
article registry for actual rendered placements. Validate those references
against the actual image pixels and captions as well as file hashes.

The editorial rebuild preserved the original article prose and URLs while
intentionally replacing/rearranging media. It did not preserve every original
image or placement. See `docs/editorial-review-20261105/` for the later review
corrections and validation boundaries.
